# EBoard Solutions - Modern Governance Platform

A modern, responsive website for EBoard Solutions - a board management platform serving educational institutions, government bodies, NGOs, and enterprises.

# Tech Stack

- **React 18** + **TypeScript**
- **Vite** - Build tool
- **Tailwind CSS** - Styling
- **Framer Motion** - Animations
- **React Router DOM** - Routing

## 📦 Installation

```bash
# Clone repository
git clone <repository-url>
cd eboard

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
